# Winamp-style Audio Visualizer (MVP)

Одностраничный визуализатор звука в духе Winamp: полноэкранная анимация на Canvas, захват системного звука или микрофона через Web Audio API. Подходит для стримов, записи экрана и фона под музыку из Spotify, браузера или любого приложения.

Файл приложения: [`visual.html`](visual.html) (или [`index.html`](index.html) → редирект).

**Демо (после публикации на GitHub Pages):** https://logmaks.github.io/Neon/

## Возможности

- **4 режима визуализации:** Spectrum Bars, Radial Spectrum, Waveform Tunnel, Particle Field
- **Источники звука:** системный звук / вкладка браузера (`getDisplayMedia`) или микрофон (`getUserMedia`)
- **Настройки в реальном времени:** сглаживание спектра, чувствительность, затухание следа
- **Оверлей «Сейчас играет»:** своё название трека (сохраняется в `localStorage`) + техническая подпись источника
- **Статус:** индикатор активного потока и счётчик FPS
- **Без сборки:** один HTML-файл, без зависимостей и сервера (с оговоркой ниже)

## Быстрый старт

1. Откройте `visual.html` в **Chrome** или **Edge** (рекомендуется).
2. Запустите музыку в Spotify, браузере или другом приложении.
3. Нажмите **«Захватить звук»** и выберите источник в диалоге ОС/браузера.
4. При необходимости введите название в поле **«Название на оверлее»** (например, `Artist — Track`).
5. Переключайте **режим** и ползунки по вкусу.

### Локальный сервер (если файл не открывается или нет захвата)

Некоторые API надёжнее работают на `http://localhost`, а не при открытии файла как `file://`:

```bash
cd Neon
python3 -m http.server 8080
```

Затем откройте: http://localhost:8080/visual.html (или http://localhost:8080/)


3. В репозитории: **Settings → Pages → Build and deployment → GitHub Actions** (workflow `Deploy GitHub Pages` подхватится после push в `main`).

## Захват Spotify и системного звука

Spotify **не отдаёт** сырой аудиопоток через публичный Web API для визуализации. Используется обходной путь:

| Сценарий | Что выбрать при захвате |
|----------|-------------------------|
| Spotify / YouTube **во вкладке** Chrome | Вкладку + включить **«Поделиться звуком вкладки»** / *Share tab audio* |
| Spotify **Desktop** | Захват экрана/окна с **системным звуком**, если ОС и браузер это поддерживают |
| Голос / инструмент | Источник **«Микрофон»** в панели |

Если после выбора источника звука нет — проверьте галочку звука вкладки или другой источник в диалоге захвата.

## Элементы управления

| Элемент | Описание |
|---------|----------|
| Захватить звук / Остановить | Старт и остановка `MediaStream` и `AudioContext` |
| Название на оверлее | Текст на нижнем оверлее; приоритет над автоматической подписью |
| Источник | Системный звук / вкладка или микрофон |
| Режим | Тип визуализации на canvas |
| Сглаживание | `AnalyserNode.smoothingTimeConstant` |
| Чувствительность | Усиление значений спектра |
| Затухание следа | Прозрачность «затухающего» фона между кадрами |

## Оверлей внизу экрана

- Пустое поле названия — показывается имя потока из браузера (если есть) или статус «Нет активного захвата».
- Заполненное поле — крупно ваше название, заголовок **«Сейчас играет»**; при активном захвате в подписи остаётся тип источника и при необходимости имя потока.
- Название сохраняется в `localStorage` под ключом `visualizer-track-title`.

## Требования

- Современный браузер с **Web Audio API** и **Screen Capture API**
- Разрешение на захват экрана/вкладки или микрофона по запросу пользователя
- Для захвата вкладки: Chrome или Edge (лучшая поддержка *tab audio*)

## Ограничения

- Нет интеграции с Spotify API (метаданные трека не подтягиваются автоматически).
- Качество и доступность системного звука зависят от ОС и политики браузера.
- На узких экранах (&lt; 720px) скрыта боковая подсказка справа; HUD и оверлей остаются.
- Запись экрана с оверлеем: HTML-панели попадают в кадр; для «чистого» видео только с canvas понадобится отдельный режим (пока не реализован).
